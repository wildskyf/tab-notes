# Tab Notes Privacy Policy

Last updated: 2026-11-13

Tab Notes does not collect, sell, or share any personal data. Its developer never receives your notes or any information about you.

## Data stored on your device
Your notes and settings (theme, font, font size) are stored locally in your browser using the extension storage API. They stay on your device.

## Network requests
Tab Notes makes no network requests. Fonts are bundled with the extension. There is no analytics or tracking.

## GitHub sync (removed)
Versions 4.0.0 to 4.0.3 contained an experimental GitHub sync that could send notes to a gist in the user's own GitHub account, using a token the user entered. Its settings were hidden, and version 4.0.4 removes it and deletes any stored token from the browser.
